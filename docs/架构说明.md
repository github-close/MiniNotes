# MiniNotes 架构说明

## 项目概述

Windows 托盘常驻极简便签工具。全局热键 / 点击托盘图标唤起，失焦自动隐藏；「待办」页（勾选列表）+「笔记」页（左列表 + 右编辑器）。数据为便携式纯文件（exe 旁 `data/` 下 `notes/*.md`、`todos.json`、`config.ini`），无数据库、无 WebView。设计目标：单 exe（约 220KB）、常驻私有内存约 4MB。支持浅色 / 暗色 / 跟随系统三档主题。

## 技术栈

- **Rust 1.97+**（`x86_64-pc-windows-msvc`），构建需 MSVC 链接器，无其他运行时依赖
- **windows-sys 0.52**：直调 Win32 API（仅编译期声明，不引入运行时）。已知特点：
  - 句柄（`HWND` 等）是 `isize` 不是指针；GDI+ 的 `GpGraphics` 等是裸指针
  - 常量类型混杂：`WS_*`/`BS_*`/`ES_*` 有 `u32` 也有 `i32`，组合时常需 `as u32`
  - 模块归属反直觉：`SetFocus`/`VK_*`/`TrackMouseEvent` 在 `Input::KeyboardAndMouse`，`WM_MOUSELEAVE`/`DRAWITEMSTRUCT`/`SetWindowTheme` 在 `UI::Controls`
  - 控件宏（如 `ListView_SetCheckState`）不存在，用 `LVM_*` 消息手写；`EM_SETCHARFORMAT`/`CHARFORMATW` 缺失（已弃用 RichEdit，改用标准 EDIT）
- **GDI+（flat API）**：圆角矩形、抗锯齿勾选框图标的绘制（`theme.rs`），内存开销约 +1MB
- **serde / serde_json**：仅用于 `todos.json` 持久化
- **winres**（build-dependencies）：编译期嵌入图标 + manifest（Common-Controls v6 + DPI aware）
- Release profile：`opt-level="z"` + LTO + `panic="abort"` + strip，产物约 220KB

## UI 架构（主题化）

- **无边框窗口**：样式为 `WS_THICKFRAME|WS_SYSMENU|WS_MINIMIZEBOX|WS_MAXIMIZEBOX`（无 CAPTION），`WM_NCCALCSIZE` 无条件返回 0 去掉非客户区——DWM 阴影、边缘拖拽调整大小、Win+方向键贴靠全部保留。注意：创建期间收到的 NCCALCSIZE 的 wParam 可能为 0，且这条消息必须在 App 就绪前就处理，否则系统边框永久残留
- **自绘层次**：标题栏（图标+标题+热键提示+关闭钮）、Tab 药丸、输入框描边都画在主窗口 `WM_PAINT`（内存 DC 双缓冲防闪烁）；按钮全部 `BS_OWNERDRAW` + 子类悬停跟踪（`theme::draw_button`，Primary/Tonal 两种）；列表行 `NM_CUSTOMDRAW` 返回 `CDRF_SKIPDEFAULT` 完全自绘（选中淡底圆角 + `ImageList_Draw` 图标 + 文字，内联重命名时交还系统）
- **勾选框图标**：本机 ImageList 不支持 alpha/mask 透明（全画成黑色不透明块，DIB 全零也一样）——因此图标不透明，背景色直接用行背景色（视觉无缝），圆圈/对勾按像素数学烘焙进 DIB（`make_checkbox_imagelist`，3 张图：纯背景/未完成/完成）。注意 COLORREF→DIB 像素必须交换 R/B（COLORREF=0x00BBGGRR，像素=0xAARRGGBB）
- **编辑器是标准多行 EDIT**（不是 RichEdit）：主题化走 `WM_CTLCOLOREDIT` 现成链路（RichEdit 不响应且其专属消息在 windows-sys 缺失）。EDIT 只认 CRLF：读文件 LF→CRLF，保存 CRLF→LF，`EM_SETLIMITTEXT` 放开 32K 上限
- **主题三档**：`theme=light|dark|system`（config.ini），system 读注册表 `AppsUseLightTheme`；`WM_SETTINGCHANGE` 时跟随系统档自动切换；`apply_theme` 重建画刷/图标列表并刷新全部控件
- **设置对话框**：checkbox 文字用 STATIC 承担（DarkMode_Explorer 下系统自绘的 checkbox 文字颜色不可控，会隐入背景；SS_NOTIFY 让点击文字也能切换）；标题栏用 `DWMWA_USE_IMMERSIVE_DARK_MODE`(20) 跟随暗色

## 关键设计决策（为什么是这样）

### 为什么用裸指针而不是 RefCell 保存全局状态

Win32 消息机制是重入的：在处理某条消息时调用 `SendMessageW`，会同步进入 wndproc 处理新消息。如果用 `RefCell<Option<App>>`，外层闭包还持有可变借用时内层再 `with_app` 就会双重借用 panic（实际踩过：`todos::rebuild` 持有借用 → `SendMessageW` → wndproc → `with_app` → panic）。

因此 App 状态用 `static mut` 裸指针保存（UI 单线程，等同 C 的 GWLP_USERDATA 模式），一律通过 `with_app(|app| ...)` 访问。

### `Option<Box<App>>` 禁止 `.read()`

`ptr::addr_of!(APP).read()` 会按值拷贝出临时 `Option<Box>`，临时值离开作用域时 Box 被误 drop，堆上的 App 被释放——之后所有堆操作都会检测到损坏（c0000374 崩溃的根源）。正确写法：`(*addr_of_mut!(APP)).is_some()`。

### match 里的常量必须真的导入

settings.rs 曾漏导入 `WM_CTLCOLOREDIT`/`WM_CTLCOLORSTATIC`，Rust 把 match 臂当成通配符绑定（新 catch-all），吞掉后续所有臂且行为诡异。编译器会报 `unreachable_patterns` 警告——看到这类警告务必当 bug 处理。

### 热键注册失败不阻塞启动

全局热键可能被其他程序占用。注册失败时自动依次尝试备选组合（Ctrl+Alt+N → Alt+Q → Ctrl+Alt+Q），成功后写回 config 并用托盘气泡告知用户；全部失败也只气泡提示，不弹阻塞对话框。

### 隐藏即保存

窗口隐藏（失焦自动隐藏 / Esc / WM_CLOSE / 最小化）和 WM_DESTROY 时：保存当前笔记、窗口位置尺寸、当前 Tab、当前笔记名到 `config.ini`。下次唤起恢复原状态。

```bash
cargo build --release   # 产物: target/release/mininotes.exe
```

Release 瘦身配置在 `Cargo.toml` 的 `[profile.release]`。
